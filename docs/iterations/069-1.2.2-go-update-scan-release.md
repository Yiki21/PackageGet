# Iteration 069：1.2.2 Go 更新扫描补丁发布

- 日期：2026-09-16
- 状态：已完成
- 主题：Go 更新扫描可靠性与跨平台补丁发布

## 目标

发布 `1.2.2`，修复 Go 扫描把 GOBIN 中的 `.gup.lock` 等非可执行文件当成 Go
程序探测，导致 Updates 页面显示 `Command manager command failed` 的问题。

## 发布范围

- [x] 过滤 GOBIN 中的非可执行文件。
- [x] 添加锁文件回归合同测试。
- [x] 更新 workspace、RPM、Arch、README 和 release notes 到 `1.2.2`。
- [x] 通过完整本地质量门禁和发布 metadata 检查。
- [x] 构建并检查 Linux 本地发布包。
- [x] 创建并推送修复后的 `Build-v1.2.2` tag，完成跨平台 Package workflow。

## 行为边界

- 可执行 Go 文件的 build-info 探测失败仍然报告错误，不会被静默忽略。
- RubyGems 继续管理所选 `gem` 可执行文件能看到的仓库。系统 Ruby 和 asdf
  Ruby 的更新列表可以不同，版本说明会保留这一点。
- 本轮不执行真实 Go、RubyGems 或其他 package manager 写操作。
