# Iteration 046：1.0.0 正式发布

- 日期：2026-08-03
- 状态：已完成
- ROADMAP阶段：阶段6跨平台发布收口
- 开发方式：直接在`main`上形成小步、线性的Git提交

## 本轮目标

在用户完成真实安装验证后，将跨平台打包产线从 beta/preview 收口为正式 `1.0.0`，并让 metadata preflight、发布说明、README 和包内版本全部接受稳定版本。

## 发布政策

- Linux、Windows、macOS 均允许 unsigned；签名、Apple notarization 和证书 secrets 不作为 1.0 门禁。
- 每个发布资产必须进入同一 bundle，并通过同一 `SHA256SUMS` 校验；CI job 和资产清单作为公开 provenance。
- Flatpak 分发继续不在 1.0 范围；现有 Flatpak manager 不受影响。

## 验收结果

- 用户确认已完成跨平台发布资产安装验证。
- workspace、RPM、Arch、README、release notes 与 tag metadata 统一为 `1.0.0`。
- Package workflow 在 `Build-v1.0.0` tag 上必须生成 17 个资产、`SHA256SUMS` 并创建非 prerelease GitHub Release。
