# Iteration 063：1.2.0 功能发布

- 日期：2026-08-04
- 状态：进行中
- ROADMAP阶段：阶段6/7跨平台发布与Package Manager生态

## 目标

在不改写既有`Build-v1.0.0`与`Build-v1.1.0`的前提下，将Gentoo
Portage、Void Linux XBPS及portable tar显式系统集成作为向后兼容功能
增量发布为`1.2.0`，继续复用17资产与统一checksum合同。

## 发布范围

- [x] 确认远端尚无`Build-v1.2.0` tag或Release。
- [x] 将workspace、RPM、Arch、README与release notes统一到`1.2.0`。
- [x] 在release notes中覆盖Portage SLOT/repository、XBPS dry-run、固定
  Polkit helper、真实容器smoke及portable tar显式安装边界。
- [x] 通过最终候选的本地串行format/check/test/clippy/build与release
  metadata preflight。
- [ ] 通过最终HEAD的Linux、Windows与macOS CI，以及main分支17资产
  Package预构建。
- [ ] 创建并推送annotated `Build-v1.2.0` tag。
- [ ] 验证tag Package workflow、公开GitHub Release、17个包资产与
  `SHA256SUMS`。

## 发布边界

- 继续采用既有unsigned政策；签名、Apple notarization与证书secrets不
  作为本功能版本门禁。
- 不移动、不删除或重新上传既有稳定版资产；`1.2.0`使用独立tag、Release
  与checksum manifest。
- tag发布前不执行真实package manager写事务；原生CI仅运行离线contract
  及官方容器中的显式ignored只读manager smoke。
- 发布资产仍为DEB/RPM/Arch、glibc/musl tar、AppImage、Windows zip/setup
  与macOS app/dmg共17项；portable tar内容扩展不增加新的顶层资产。
- portable tar只携带系统集成文件；只有用户显式以root运行installer才写入
  固定`/usr`路径。AppImage继续不提供系统manager写能力。
