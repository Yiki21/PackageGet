# Iteration 060：1.1.0 功能发布

- 日期：2026-08-04
- 状态：已完成
- ROADMAP阶段：阶段6/7跨平台发布与Package Manager生态

## 目标

在不改写既有`Build-v1.0.0` tag和Release的前提下，将其后的Package Managers管理能力、Windows manager与Bun Global向后兼容功能增量作为`1.1.0`发布，并复用既有17资产跨平台产线与统一checksum合同。

## 发布范围

- [x] 确认`Build-v1.0.0`已存在且不可复用，远端尚无`Build-v1.1.0` tag或Release。
- [x] 将workspace、RPM、Arch、README与release notes统一到`1.1.0`。
- [x] 在release notes中覆盖Package Managers管理/健康页、Scoop、Chocolatey、Bun Global、按需详情和manager contract收口。
- [x] 通过本地串行format/check/test/clippy/build及release metadata preflight。
- [x] 通过最终HEAD的Linux、Windows与macOS CI，以及main分支17资产Package预构建。
- [x] 创建并推送annotated `Build-v1.1.0` tag。
- [x] 验证tag Package workflow、公开GitHub Release、17个包资产与`SHA256SUMS`。

## 发布边界

- 继续采用1.0既定unsigned政策；签名、Apple notarization与证书secrets不作为本功能版本门禁。
- 不移动、不删除、不重新上传`Build-v1.0.0`资产；`1.1.0`使用独立tag、Release和checksum manifest。
- tag发布前不执行真实package manager写操作；原生CI仅运行离线contract和已存在宿主CLI的显式ignored只读smoke。
- 发布资产维持DEB/RPM/Arch、glibc/musl tar、AppImage、Windows zip/setup与macOS app/dmg共17项。
