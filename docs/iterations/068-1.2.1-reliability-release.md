## 发布边界

- 继续采用既有 unsigned 政策；签名、Apple notarization 与证书 secrets 不
  作为本补丁版本门禁。
- 不移动、删除、重打或重新上传既有稳定版资产；`1.2.1` 使用独立 tag、Release
  与 checksum manifest。
- tag 发布前不执行真实 package manager 写事务；测试和原生 CI 只运行离线
  contract、只读 smoke 与受控 fake CLI。
- 发布资产仍为 DEB/RPM/Arch、glibc/musl tar、AppImage、Windows zip/setup
  与 macOS app/dmg 共 17 项，另附一个 `SHA256SUMS`。
- 本补丁不引入持久化 package/Health cache、后台定时刷新或新的 manager；首次
  访问数据页仍读取真实 package manager 状态。
